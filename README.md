# OmniVision

Современный адаптивный лендинг для платформы OmniVision, созданный на React JS с использованием Tailwind CSS.

## 🚀 О проекте

Это современный одностраничный сайт, полностью адаптированный под все устройства. Проект демонстрирует ключевые преимущества платформы OmniVision с фокусом на пользовательский опыт и визуальную привлекательность.

## ✨ Особенности

- **📱 Полная адаптивность** - Идельное отображение на всех устройствах
- **⚡ Высокая производительность** - Быстрая загрузка благодаря Vite
- **🎨 Современный дизайн** - Чистый и привлекательный интерфейс
- **🌈 Tailwind CSS** - Гибкая и удобная система стилей
